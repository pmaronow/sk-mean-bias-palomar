## Reproduction

Install elan, Git, Python 3.11 or later and the pinned packages in [requirements-verification.txt](../requirements-verification.txt). The default Comparator sandbox requires Linux with working bubblewrap namespaces. The full private-import proof audits require Linux `vm.max_map_count` of at least `262144`; have the administrator configure this kernel setting on the verification host or container environment before verification. The scripts check this prerequisite before loading the large proof development. From the repository root:

```sh
python3 -m pip install -r requirements-verification.txt
lake exe cache get
SK_VERIFY_LOG_DIR=/absolute/path/outside/repository ./scripts/verify.sh
```

The pipeline freezes all public regular files and records the commit and dirty state before work. It requires all nine passes and unchanged full-tree and mathematical/compiler hashes before reporting success. Downloaded validators, generated audits, build transcripts and receipts stay outside the source tree. Individual tools are [check_repository.py](../scripts/check_repository.py), [check_metadata.py](../scripts/check_metadata.py), [check_statement_preservation.py](../scripts/check_statement_preservation.py), [check_numbered_claims.py](../scripts/check_numbered_claims.py), [audit_selected_proofs.py](../scripts/audit_selected_proofs.py) and [verify-comparator.sh](../scripts/verify-comparator.sh).

The generated numbered and selected audits deliberately use ordinary non-module imports, which load transitive private proof bodies in Lean 4.35. Each theorem anchor must be a proposition with an actual theorem-body declaration. Imported compiled artifacts and their source hashes remain fixed during each audit. Independent kernel replay applies to the selected interface; the broader numbered-target audit separately checks its exact types, loaded bodies and transitive axioms. The exact target declarations were elaborated and type-checked. Their printed records retain explicit binders and universes, while suppressing proof-term arguments with `pp.proofs=false`; the hashes identify those compiler pretty-printed displays, not serialized kernel expressions. Printed types, matching names and kernel checks do not mechanically prove equivalence to a TeX or English claim. The separate mathematical fidelity review was automated.
